# Setup for abdullah-versioning

The owner asked to set up this project's releases, or to refresh a setup done before.

1. Call the Skill tool with `abdullah-versioning` (listed as `abdullah-skills:abdullah-versioning` when installed as a plugin).
2. Follow its `reference/setup.md` from step 1. On a project that is already set up, follow its section "Re-running the setup".
3. Write nothing in the project until the owner has seen the drafts and agreed.

If the `abdullah-versioning` skill is not available, tell the owner to install it from https://github.com/abdoo431/abdullah-skills, and stop.
